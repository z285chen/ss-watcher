## 本轮已实现

- Collector 生成有界资源候选：顶层 document、DOM script/link/iframe/image，以及 Performance Resource Timing 的 URL、initiator、transferSize、duration；同一资源合并 DOM/Timing 来源。
- URL 在 Collector 与 SW 双重校验：只接受 HTTP(S)、去 credentials/fragment；只保留 `v`、`ver`、`version` 缓存键，其他 query 删除并标为 `redacted`，对应资源只能 metadata-only。
- SW 将候选注册成随 ScanSession 存储和销毁的 `resourceId` capability。Side Panel 的正文请求消息不接受 URL、path 或 host。
- ResourcePolicy 仅读取当前会话同源的 `document | script | style | json | source-map`，固定 `credentials: "omit"`、`redirect: "error"`、`cache: "no-store"`、`referrerPolicy: "no-referrer"`。
- SW 强制正文预算：并发 2、正文 100 个、总计 20 MB；普通文件 2 MB、source map 5 MB、单请求 12 秒。M3 扫描结束、取消、吊销、导航、标签/窗口变化时释放预算状态。显式取消还会清空本会话全部观察/派生资源 capability，但保留非资源会话和旧 committed 快照。
- external `sourceMappingURL` 已闭环：只有 SW 成功读取一个已注册、同源且已分析的 JS/CSS 父资源后，才可从正文派生同源 map capability；Side Panel 不能提交 map URL。派生项记录 `source-map-reference` 与 `derivedFromResourceId`，按会话串行注册、URL 去重，最多 24 个且随会话吊销。
- MIME allowlist、流式大小中止和 SHA-256 已实现；正文只在 Side Panel 当前分析 Promise 中短暂存在，不进入 ScanSession、IndexedDB、日志或完整 JSON 导出。
- `token-url-v2` 轻量分析器已实现：framework/theme、API path/GraphQL operation“代码引用”、Resource Timing 性能提示、外部/内嵌 source map 安全摘要，以及稳定 App/Pixel 规则。分析器不使用 eval、动态 import、DOM 注入、远程 Worker 或远程解析服务。
- `public-signals-v1.0.0` 固化 40 条稳定规则（32 Apps、8 Pixels）。每条规则至少 3 个信号组，判定至少需要同一观察资源上的 2 个独立信号；禁止把一个资源的供应商域名与另一无关资源的通用路径拼接成命中。
- committed 快照保存脱敏 ResourceDescriptor、MIME、字节数、hash、finding 与最多 256 字符证据；Technology 页面独立展示，M3 部分失败不阻止产品和 M2 分析提交。
- Technology 页面提供独立“公开源码导出”：导出前显示同源文件数、预计字节与来源；点击后用新预算 scope 重新按 resourceId 读取，记录扫描/导出 hash 及变化标志，支持取消，完成后释放正文引用。普通完整 JSON 增加 raw-source 字段剥离门禁，仍不包含源码正文。
- `PARTIAL` 页面现在显示 failed/skipped 数量及 failureReason 分布；JSON-LD `sameAs` 仅作为 Organization/Store/Brand/WebSite 等店铺主体的社交账号回退，不覆盖 DOM 已发现账号。
- Technology 页面优先显示派生 source map 及父 capability 摘要，并展示指纹规则版本；UI 明示严格沙箱/服务端 Pixel 盲区，以及 Pixel 命中不等于访问量或事件已送达。
- manifest 权限没有扩张：仍为 `activeTab`、`scripting`、`storage`、`sidePanel`；`optional_host_permissions` 为空，无 `<all_urls>`、`debugger`、Cookie 权限。
