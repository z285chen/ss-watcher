# M2 分析与导出实现记录

> 状态：COMPLETE
> 完成日期：2026-07-20

## 已实现

- 匿名上下文与价格门禁：同一 SW/origin/routeRoot/omit 口径验证 country、`cart.js` currency 与实际价格来源；B 级 `products.json` 通过精确 product/variant ID 与官方 `.js` 样本核对。
- 店铺统计：产品/变体/库存、经验证的价格最小值/最大值/平均值、折扣产品与变体、Vendor/Product Type/Tag 分布及时间范围。价格口径未验证时不生成价格区间。
- 公开畅销：读取 `sort_by=best-selling`，保留真实 `all-storefront` 或具体 Collection scope、原始公开顺序和“公开排序不等于真实销量”声明；分页只接受严格 `n+1`。
- 上新证据：A=`createdAt`、B=`publishedAt`、C=`created-descending` 公开相对顺序、D=sitemap `lastmod`；C/D 不被包装成确定上架日期。
- 正式产品表：搜索 ID/handle/title/Vendor/Product Type/Tag/SKU，支持 Vendor/Product Type/Tag/库存筛选、确定性排序与分页。
- 原子持久化：detection、catalog、price-context、statistics、rankings、newness 六个模块全部达到终态后才 commit；UI、产品表与导出只读取 `committed: true`。
- 导出：RFC 4180 CSV、`= + - @ Tab CR` 公式注入防护、无损 `productJson` 往返、CSV `.meta.json` sidecar、完整 JSON 与扫描上下文/覆盖率/截断/行数/生成时间元数据。
- Side Panel：Overview、Products、Diagnostics 三页；不复制 PPSpy UI。可见验收发现深层 Vue Proxy 导致 Products/Export 的 `structuredClone` DOMException，已改为 immutable committed bundle `shallowRef` 并加入回归测试。

## 与本机 PPSpy 的 M2 范围对照

本机安装的 PPSpy 1.6.7 客户端证据显示其非销量产品分析核心包含 Best Selling、Newly Added、All Products、Product Statistics、Vendor/Product Type/Tag、价格/时间字段以及单选/多选/全量 CSV。M2 已在不复制 UI、品牌、代码或私有接口的前提下覆盖这些产品分析能力，并额外提供证据等级、scope 声明、匿名价格门禁、原子快照和公式注入防护。

这里的“核心一致”严格限定为 M0–M2 的公开店铺/产品分析范围，不包含销量间谍，也不冒充完整 PPSpy：App/Pixel、评论供应商与历史差异分别属于 M3、M5、M4。
